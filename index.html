Core Objective

Project Overview

Bridging the critical gap between line-tracking precision and reactive spatial navigation

The Problem with Traditional Line Followers

Standard line-following robots rely exclusively on down-facing infrared (IR) sensors. While effective for strict track alignment, they operate blindly regarding ambient space:

  • ✕ Immediate head-on collisions with stationary or dynamic objects on the line.
  • ✕ Complete mission halt or mechanical stall when paths are obstructed.
  • ✕ Inability to inspect alternate lateral bypass trajectories.

The Sensor Fusion Solution

This project implements a multi-layer autonomous architecture combining real-time optical tracking, ultrasonic ranging, servo sweeping, and priority-driven state transitions:

  • ✓ Line Detection: Continuous dual-IR tracking with PWM differential steering.
  • ✓ Dynamic Sonar Scanning: 180° servo sweeps evaluate left vs. right clearance.
  • ✓ Deterministic Bypass & Reacquisition: Executes safe bypass arc, hunts for the line, and seamlessly rejoins without human intervention.

PRIORITY ARBITRATION RULE

Obstacle Avoidance has strict preemptive priority over Line Following. In embedded C/C++, if ultrasonic distance is below safety limit (e.g. dist < OBSTACLE_LIMIT_CM), the interrupt evaluation immediately suspends line PID/PWM updates, transitions the system into STOP_SCAN, and prevents collision regardless of line sensor status.

Software & Control Architecture

Structured embedded C/C++ firmware running non-blocking deterministic cycles

Arduino IDE & Embedded C/C++

Compiled bare-metal firmware with zero operating system overhead for deterministic microsecond execution.

02

Non-Blocking State Loop

Replaces blocking delay() with millis() timer checks to ensure continuous sonar polling during motion.

03

PWM Motor Differential Steering

Proportional speed adjustments to left/right motors allow smooth angular corrections along track curves.

04

Ultrasonic Time-of-Flight Ranging

Triggers 10µs pulses on HC-SR04 pin and measures echo reflection duration converted via sound speed constant (343 m/s).

05

Priority-Based Decision Arbiter

Evaluates safety triggers ahead of tracking routines, ensuring collision-free operation at all times.

// Non-blocking main control loop with FSM
void loop() {
  long dist = readUltrasonicDistance();

  switch (currentState) {
    case STATE_LINE_FOLLOW:
      if (dist < OBSTACLE_THRESHOLD_CM) {
        stopMotors();
        currentState = STATE_OBSTACLE_DETECTED;
      } else {
        executeLineFollowing();
      }
      break;

    case STATE_OBSTACLE_DETECTED:
      panScanSurroundings();
      currentState = STATE_STOP_SCAN;
      break;

    case STATE_STOP_SCAN:
      int safeDir = evaluateClearance();
      executeAvoidBypass(safeDir);
      currentState = STATE_AVOID;
      break;

    case STATE_AVOID:
      if (bypassCurveComplete()) {
        currentState = STATE_SEARCH_LINE;
      }
      break;

    case STATE_SEARCH_LINE:
      if (irSensorDetectedLine()) {
        realignToTrack();
        currentState = STATE_LINE_FOLLOW;
      }
      break;
  }
}
